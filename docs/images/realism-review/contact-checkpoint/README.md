# Contact-work review evidence

1 November 2026 checkpoint. `snap-review.mp4` uses the review-only entry index with native source
poses adapted to engine grips, body proportions and physical tracking. It is gameplay at 30 fps,
not the original 20 fps recording. GR, level 60, seed 2, continuous warm-up 100 ticks, capture
180 ticks. Diagnostic spheres show pelvis targets. It precedes the final acquisition-target
change and does not establish stable palm holds or correct sole placement.

The four `*-camera-sample.jpg` files are uncropped original Harmony4D cam01 photographs sampled
when reviewing the newly imported takes. Corresponding camera-provenance JSON files retain
archive members and source-frame mapping. These sparse samples establish context, not continuous
contact annotations or elite technique acceptance.

Source: [Harmony4D](https://huggingface.co/datasets/Jyun-Ting/Harmony4D), Khirodkar, Song, Cao,
Luo and Kitani, Carnegie Mellon University, NeurIPS 2024, MIT. Character bases are MakeHuman CC0.
See [the checkpoint](../../../checkpoints/2026-11-01-motion-contacts.md) for current limitations
and exact continuation work.
