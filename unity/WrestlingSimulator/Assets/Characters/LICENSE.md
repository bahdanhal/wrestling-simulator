# Character assets

The models and textures in this folder are generated from MakeHuman assets
(`makehuman_system_assets`, `skins01`, `skins02` asset packs) with the MPFB2 Blender
extension, by `tools/characters/build_wrestlers.py`.

All source assets used are released under CC0 1.0 (public domain dedication) by the
MakeHuman project and the individual skin authors. See
https://static.makehumancommunity.org/assets/assetpacks/index.html
